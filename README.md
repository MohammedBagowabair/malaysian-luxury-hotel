# Serai Tanjung Langkawi — hotel landing page (demo)

Live: https://mohammedbagowabair.github.io/malaysian-luxury-hotel/

A landing page for **Serai Tanjung**, a fictional five-star rainforest-and-sea resort on Langkawi, Malaysia.
The brand, rooms, offers and quotes are fictional; photos are illustrative. Enquiries go to WhatsApp **+60 11-5119 8497**.

Stack: Vite, React 19, TypeScript, Tailwind CSS v4.

```sh
npm install
npm run dev
BASE_PATH=/malaysian-luxury-hotel/ npm run build   # static site in dist/
```
